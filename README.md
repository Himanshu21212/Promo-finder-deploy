Promo Finder
Turn timestamped microdrama screenplays into a ranked shortlist of
promo clips.

Promo Finder helps editors find 20--60 second hooks and cliffhangers
across a season of episodes. It combines deterministic screenplay
analysis with AI-assisted editorial review, while keeping the editor in
control.

What you get
For every selected promo, the tool provides:
- Exact source timestamps for each segment
- Hook and cliffhanger identified from the screenplay
- Why it may work as a promo
- Editor flags for context, pacing, and potential spoilers
- Ranked results with downloadable reports
Supports both continuous clips and stitched moments from different parts
of a story.
How it works
1. Parse: Convert screenplay files into timestamped dialogue and
   action beats.
2. Find moments: Detect potential hooks and cliffhangers.
3. Generate cuts: Build 20--60 second single and stitched
   candidates.
4. Rank: Score candidates for hook, cliffhanger, momentum, clarity,
   length, and premise fit.
5. Review with AI: Sarvam evaluates shortlisted cuts and can
   suggest trims.
6. Validate: Code checks every timestamp and rejects trims that
   break hard constraints.
7. Human approval: Editors review the shortlist and choose the
   final clips.
Key design decision: AI can judge and suggest; it cannot invent
timestamps. All timestamps are resolved and validated against the
original screenplay.
The app workflow
1. Upload screenplay .txt files or a ZIP.
2. Enter or edit the show title.
3. Click Find promos.
4. Follow the analysis stages and review the report.
5. Download the outputs or choose New analysis to start again.
The web app uses the configured Sarvam service automatically. API keys
and provider settings stay server-side; they are not exposed in the
interface.
AI, reliability & transparency
- AI scores are blended 50/50 with the rules score.
- Invalid AI trims are rejected by code.
- Malformed responses retain the rules score.
- Rate limits, timeouts, invalid credentials, and exhausted credits
  are handled explicitly.
- If AI review is unavailable, the app reports the failure and can
  offer an explicitly selected rules-only backup.
Evaluation status: The included 50-episode archive is rules-only
(real_ai_calls: 0). Sarvam integration tests use simulated responses
to test request handling and guardrails; they do not prove live AI
editorial quality. A successful live run and human review are needed to
evaluate that quality.
Run locally
Requires Python 3.11+.
pip install -r requirements.txt

# Start the web app
streamlit run app.py

# Or run the CLI on a folder, ZIP, or .txt file
python -m promo_finder "path/to/scripts.zip" -o outputs
Try the workflow with the included two-episode demo:
python -m promo_finder samples/demo_show.zip -m rules -o outputs
For Sarvam AI, set SARVAM_API_KEY locally or in Streamlit Community
Cloud secrets. Never commit API keys.
Tests & engineering
Run the test suite:
pip install -r requirements-dev.txt
python -m pytest -q
Latest recorded test run: 64 passed.

The tests cover parsing edge cases, ranking constraints, invalid AI
suggestions, timestamp protection, API failure handling, CLI execution,
and Streamlit workflows. Sarvam API tests use simulated HTTP responses.
Known limitations
- The system analyses screenplays, not video footage; it cannot
  verify visual impact.
- Current English-language lexicons are tuned mainly to romance and
  revenge microdramas.
- Rules-only explanations can be generic or occasionally inaccurate.
- Scores rank clips within a show; they do not predict views,
  installs, or revenue.
- AI can only rerank candidates generated by the rules pipeline; it
  cannot recover moments that candidate generation misses.

  cli.py          # command-line interface

tests/            # automated tests
